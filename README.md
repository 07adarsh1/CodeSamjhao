## ✨ Core Features

### 1. ⚡ Real-Time Groq AI Inference
- Powered by ultra-fast inference on **Groq Cloud API** using `llama-3.3-70b-versatile` (with fallback support for `openai/gpt-oss-120b`).
- Near instantaneous response generation with structured JSON schema extraction.
- Automatic offline simulation fallback if an API key is not present.

---

### 2. 🚨 Error Debugger Mode (Dual Textareas)
Instead of forcing you to mix your code and stacktraces, Error Mode provides two dedicated input zones:
1. **Terminal / Console Stacktrace**: Paste messy exceptions, Python tracebacks, or npm crashes.
2. **Associated Code**: Paste the relevant function or block where the error occurred.

The output is formatted into four structured, actionable cards:
- **🚨 ERROR KYA HAI?**: A plain-English/Hinglish translation devoid of cryptic jargon.
- **🍛 KYU AAYA?**: Root-cause analysis explained through a relatable desi real-world analogy.
- **🛠️ FIX KAISE KARE?**: Step-by-step remediation accompanied by **complete corrected working code** and a 1-click **📋 Copy Fix Code** button.
- **💡 SENIOR PRO TIP**: Authentic senior dev advice (*"Dekh bhai, production pe aisa mat karna..."*).

### 4. 🍛 Diverse Desi Analogy Engine
To prevent repetitive analogies, the system draws dynamically from a rich collection of authentic Indian cultural experiences:
- 🚆 **Mumbai Local / Delhi Metro Rush**: Parallel processing, thread pooling, and resource contention.
- 🎫 **10 AM IRCTC Tatkal Booking**: Race conditions, high concurrency, and sudden server timeouts.
- 🥙 **Panipuri Counter Token Line**: Strict FIFO queues, buffer overflows, and memory spikes.
- 📒 **Kirana Store Bahi-Khata**: State persistence, key-value caches, and ledger transactions.
- 🍱 **Mumbai Dabbawala Network**: Fault-tolerant routing, packet switching, and distributed systems.
- 🏏 **Gully Cricket Rules**: "Jo ball khoega wahi layega" (resource cleanup/RAII), last-man batting edge cases.
- 🛵 **Swiggy / Zomato Delivery Order**: Asynchronous fetch/promises, polling, and WebSocket status tracking.
- 🎺 **Shaadi Baraat Traffic Jam**: Deadlocks, blocking I/O, and single-threaded bottlenecks.

### 5. 🎯 Interactive MCQ Quiz Engine ("Quiz Bana de")
Clicking **"Quiz Bana de 🎯"** triggers Groq to analyze the code and generate 3 interactive MCQs:
- **Direct Interactive Buttons**: Options are rendered as chunky `.neo-btn` buttons with letter badges (`A)`, `B)`, `C)`, `D)`).
- **Instant Visual Feedback**:
  - Selected correct answer turns **Neon Green** with `✓ SAHI`.
  - Selected incorrect answer turns **Neon Red** with `✗ GALAT` while clearly highlighting the correct choice.
  - Step-by-step Hinglish explanation card reveals why that option is right or wrong.
- **Scoreboard & Feedback**: Real-time score tally (`🏆 SCORE: 3 / 3`) with senior dev commentary.
- **Action Controls**: `🔄 Reset Answers` to test again or `⚡ Naya Quiz` to generate new questions.
- **Auto-Scroll**: Automatically scrolls smoothly to the quiz container upon generation.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/) / [pnpm](https://pnpm.io/)
- A free [Groq API Key](https://console.groq.com/keys)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/hinglish-explainer-react.git
   cd hinglish-explainer-react
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

### Environment Setup

1. Copy the example environment file:
   ```bash
   cp .env.example .env
   ```

2. Open `.env` and add your Groq API key:
   ```env
   VITE_GROQ_API_KEY=gsk_your_groq_api_key_here
   ```
   > 💡 *Don't have a Groq key yet? Get one free at [console.groq.com](https://console.groq.com/keys). The app also features an offline demo mode that works out-of-the-box!*

### Run Development Server

```bash
npm run dev
```
Navigate to **`http://localhost:5173`** in your browser.

### Build for Production

```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory. You can preview it with:
```bash
npm run preview
```

## 🔒 Security & Secrets Management

- **Zero Key Leakage**: `.env` is explicitly listed in `.gitignore` to prevent committing sensitive credentials.
- **Safe Template Included**: `.env.example` provides the key structure without containing any secrets.
- **Client-Side Storage**: Groq API calls are made directly from the client using the configured `VITE_GROQ_API_KEY`. For strict enterprise setups, a serverless proxy (e.g. Next.js API route or Cloudflare Worker) can be dropped in.

## 🌐 Production Deployment

### Deploying to Vercel

1. Push your code to GitHub.
2. Log into [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Select your repository.
4. Under **Environment Variables**, add:
   - **Name**: `VITE_GROQ_API_KEY`
   - **Value**: `gsk_your_groq_api_key_here`
5. Click **Deploy**.

### Deploying to Netlify

1. Connect your repository in [Netlify](https://www.netlify.com).
2. Set Build Command to `npm run build` and Publish Directory to `dist`.
3. In **Site Configuration > Environment Variables**, add `VITE_GROQ_API_KEY`.
4. Deploy site!
